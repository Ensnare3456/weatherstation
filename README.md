# weatherstation
Hi, I build here a local weatherstation!
I want to build a small, simple weather station that works completely locally without an internet connection.
The device will measure the current temperature using a temperature sensor and display it on a small screen. The main goal is to keep the project compact, simple, and energy-efficient. The goal is always to last long be useful on long trips outdoors (camping, etc...)
